# Astrophysical Objects Recognition

## Overview

This repository contains the final project developed for the **Laboratory of Computational Physics Mod b** course. The project focuses on the application of **Machine Learning techniques to the classification of astrophysical objects**, using data from the Sloan Digital Sky Survey (SDSS).

The work was carried out as a collaborative university project and combines concepts from **astrophysics**, **data analysis**, and **machine learning**, with particular attention to scientific software development and collaborative programming practices.

---

## Project Goals

The project was designed with both scientific and computational objectives in mind. The main goals were:

- **Understand the physical nature of different astrophysical objects**, in particular:
  - **Stars**, which are relatively nearby stellar sources and generally appear as point-like objects;
  - **Galaxies**, extended systems composed of billions of stars and observed over a wide range of distances;
  - **Quasars (QSOs)**, extremely luminous active galactic nuclei that are typically located at cosmological distances.

- **Become familiar with a pre-existing codebase**, understanding its structure and workflow.

- **Explore and understand the dataset**, including its features, labels, and astrophysical meaning.

- **Identify the different stages of the machine learning pipeline**, namely:
  - data preprocessing,
  - model training,
  - model evaluation,
  - inference and prediction.

- **Compare different machine learning approaches** on the same astrophysical classification problem, analyzing their strengths and limitations.

- **Develop collaborative software engineering skills**, working on a shared GitHub repository and managing contributions from multiple team members.

- **Organize the work in parallel**, dividing tasks among team members while maintaining a coherent and reproducible codebase.

---

## Learning Outcomes

Through this project, we gained experience in:

- Applying machine learning methods to real scientific data.
- Interpreting astrophysical datasets and understanding their physical implications.
- Working with a medium-sized Python codebase.
- Using version control systems and collaborative development workflows.
- Conducting scientific analyses in a reproducible and organized manner.
